# 投影仪 GUI 开发大纲

> 状态：设计已确认，下一阶段从 M1 只读状态页开始实现。当前只有临时 wash 滑块；正式 GUI 按本文分阶段实现。
> 相关文档：[项目规划](../PLANNING.md)、[待办](../TODO.md)、[指令](../COMMANDS.md)。

## 1. 目标

给投影仪一个**服务端权威**、可扩展的控制界面，覆盖光学、灯泡、配对和物理模拟开关。GUI 不应只是一个参数面板；它要能解释当前状态、限制非法值，并让玩家在影院里调完就走。

非目标：

- 不在 GUI 里做视频文件浏览器（属于 AV Receiver）
- 不在 GUI 里做播放/暂停/seek/解码状态（属于 AV Receiver）
- 不在 GUI 里做扬声器路由（属于 AV Receiver）
- 不做实时 3D 预览；用数值 + 小示意图即可

## 2.1 职责边界

投影仪只接收来自 **AV Receiver** 的视频信号：

- 投影仪 GUI 不选择文件、不解码、不控制播放。
- 投影仪 GUI 不显示 codec/丢帧/FFmpeg 等信息。
- 投影仪只管理：光学、灯泡、画面物理效果、屏幕配对。
- 扬声器只接收 AV Receiver 分配的音频声道，不做解码。

AV Receiver 才负责：媒体文件、FFmpeg、播放状态、音画时钟、视频/音频分发。

## 3. 交互模型

### 打开方式

- 右键投影仪方块打开 GUI。
- 后续增加**遥控器工具**：在远处右键投影仪/接收器也能打开同一 GUI。
- 配对工具（线材/配对器）独立于 GUI，用于建立投影仪↔屏幕、接收器↔扬声器关系。

### 数值编辑

- 滑块 + 右侧数值文本（保留 2 位小数）。
- 滑块只改本地草稿；`应用` 才写入 block entity。
- `完成` = 应用并关闭；`取消` = 丢弃草稿并关闭。
- 不需要“Apply + Done 两个都保存”的重复按钮。

### 物理模拟开关

每个物理项有独立开关和数值：

| 开关 | 关闭后的行为 |
|---|---|
| 对焦模糊 | 始终清晰，仍保留焦距数值 |
| 梯形校正 | 不做 UV 预畸变 |
| 环境光洗白 | wash 强制视为 0 |
| 灯泡预热 | 灯泡立即达到目标亮度 |
| 风扇声 | 不播放风扇循环 |

开关状态保存在投影仪 block entity 中，并同步到客户端。

- 固定宽度约 320–360 px，随 GUI scale 缩放。
- 分组之间留 8–12 px；标签与控件不能重叠。
- 数值文本右对齐；滑块宽度固定，避免抖动。
- 禁用项变灰，但保留显示值。

## 6. 网络与权威

- GUI 不直接依赖聊天命令。
- 新增 C2S `UpdateProjectorSettings` 包：
  - 字段：投影仪 pos、设置项 id、数值/布尔
  - 服务端校验范围、距离、权限、方块仍是投影仪
  - 更新 block entity → `setChanged()` → `sendBlockUpdated`
- 也可以一次提交整个设置快照（Apply 时），减少包数量。
- 服务端拒绝时回发当前快照，客户端 GUI 回滚。
- 频率限制：每 tick 最多 1 个设置包；拖动滑块不逐帧发送，Apply 时一次发送。
- 远程遥控器：同一 GUI，但操作目标由遥控器 item 的绑定提供。

## 7. 服务端/客户端职责

- 服务端：权威数值、校验、持久化、配对关系。
- 客户端：草稿、控件状态、格式化显示、预测预览（可选）。
- 客户端只在 Apply 时提交；预览不应覆盖服务端权威值。
- GUI 关闭后不保留客户端草稿。

## 8. 分阶段实现

### M0：临时 fixes（当前）

- 删除 Apply/Done 重复：Done 保存并关闭，Cancel 丢弃。
- 修正标题、说明、滑块、按钮的垂直布局，避免重叠。
- 保留 wash 滑块作为临时入口。

### M1：只读状态页

- 右键打开 GUI。
- 显示配对屏幕、距离、灯泡、AV 输入信号状态。
- 不提供编辑，先验证 GUI 生命周期和服务端数据读取。

### M2：光学与 wash 编辑

- 投掷比、焦距、梯形、亮度、wash 滑块。
- Done/Cancel 语义；服务端包校验。
- 命令与 GUI 共用同一套 setter。

### M3：物理模拟开关

- 对焦/梯形/wash/预热开关。
- 关闭后渲染路径跳过对应计算。
- 这些开关必须能在专用服务器上保存并同步。

### M4：配对/诊断

- 重新扫描屏幕；显示当前配对原因（距离/朝向/遮挡）。
- 配对工具（线材/配对器）入口。
- 显示 AV 输入信号状态，不显示解码细节。

### M5：遥控器

- 遥控器 item，可绑定投影仪/接收器。
- 在远处打开同一 GUI。
- 权限和距离限制。

## 9. 测试清单

- GUI scale 1/2/3/4 下无重叠、无裁切
- 键鼠操作：Tab、Esc、Enter、方向键、滑块拖动
- 数值边界：最小值、最大值、NaN、超范围
- Done/Cancel/Esc 的行为一致
- 单人、LAN 客户端、专用服务器
- 投影仪被拆除、屏幕被拆除、切换维度
- 物理开关关闭后行为确实变化
- 2 个投影仪/屏幕时目标正确
- 本地化：中文/英文长度不溢出
- 与 Iris/BSL 同时运行不崩溃
