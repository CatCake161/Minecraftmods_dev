# 投影仪 GUI 开发大纲

> 状态：M1 只读状态页 + M2 光学/wash 编辑 + M3 物理模拟开关已通过游戏内验收；线材显式配对（本文件 M4）已通过游戏内验收；配对诊断与 M5 遥控器未做；对焦模糊物理观感一般，后续改进。
> 相关文档：[项目规划](../PLANNING.md)、[待办](../TODO.md)、[指令](../COMMANDS.md)。

## 1. 目标

给投影仪一个**服务端权威**、可扩展的控制界面，覆盖光学、灯泡、配对和物理模拟开关。GUI 不应只是一个参数面板；它要能解释当前状态、限制非法值，并让玩家在影院里调完就走。

非目标：

- 不在 GUI 里做视频文件浏览器（属于 AV Receiver）
- 不在 GUI 里做播放/暂停/seek/解码状态（属于 AV Receiver）
- 不在 GUI 里做扬声器路由（属于 AV Receiver）
- 不做实时 3D 预览；用数值 + 小示意图即可

## 2.1 职责边界

投影仪只接收来自 **AV Receiver** 的视频信号：

- 投影仪 GUI 不选择文件、不解码、不控制播放。
- 投影仪 GUI 不显示 codec/丢帧/FFmpeg 等信息。
- 投影仪只管理：光学、灯泡、画面物理效果、屏幕配对。
- 扬声器只接收 AV Receiver 分配的音频声道，不做解码。

AV Receiver 才负责：媒体文件、FFmpeg、播放状态、音画时钟、视频/音频分发。

## 3. 交互模型

### 打开方式

- 空手右键投影仪方块打开 GUI。
- 后续增加**遥控器工具**：在远处右键投影仪/接收器也能打开同一 GUI。
- 配对工具（线材/配对器）独立于 GUI，用于建立投影仪↔屏幕、接收器↔投影仪、接收器↔扬声器关系。

### 数值编辑

- 滑块 + 右侧数值文本（保留 2 位小数）。
- **改动即保存**：按钮切换立即发送完整快照；滑块拖动/释放后约 200 ms debounce 发送，避免每帧发包。
- 没有 `Apply` / `Done` / `Cancel`；`Close` 只关闭，`Esc` 也只关闭。改动已经在关闭前/关闭时提交。
- 服务端校验失败时发聊天提示；GUI 不保留旧的“取消回滚”草稿。

### 物理模拟开关

每个物理项有独立开关和数值：

| 开关 | 关闭后的行为 |
|---|---|
| 对焦模糊 | 始终清晰，仍保留焦距数值 |
| 梯形校正 | 不做 UV 预畸变 |
| 环境光洗白 | wash 强制视为 0 |
| 灯泡预热 | 灯泡立即达到目标亮度 |
| 风扇声 | 不播放风扇循环 |

开关状态保存在投影仪 block entity 中，并同步到客户端。

- 禁用项变灰，但保留显示值。

## 6. 网络与权威

- GUI 不直接依赖聊天命令。
- C2S `ProjectorSettingsPayload`：
  - 字段：投影仪 pos、设置项 id、数值/布尔
  - 服务端校验范围、距离、权限、方块仍是投影仪
  - 更新 block entity → `setChanged()` → `sendBlockUpdated`
- 实际实现一次提交整个设置快照，减少包数量。
- 服务端拒绝时发聊天错误；GUI 不保留旧草稿，重新打开读取 block entity 当前值。
- 频率限制：按钮切换立即发送；滑块约 200 ms debounce，不逐帧发送；Close/Esc 前 flush。
- 远程遥控器：同一 GUI，但操作目标由遥控器 item 的绑定提供。

## 7. 服务端/客户端职责

- 服务端：权威数值、校验、持久化、配对关系。
- 客户端：控件状态、格式化显示、改动 debounce/提交、预测预览（可选）。
- 客户端改动即提交快照；服务端返回的 block entity 值仍是权威值。
- GUI 关闭后不保留客户端草稿；关闭前 flush 未发送的滑块改动。

## 8. 分阶段实现

### M0：临时 fixes（已完成，被正式 GUI 取代）

- 删除 Apply/Done 重复：正式面板改为改动即保存。
- 修正标题、说明、滑块、按钮的垂直布局，避免重叠。
- 临时 wash 滑块已被 M2 正式面板取代。

### M1：只读状态页（已实现）

- 空手右键打开 GUI。
- 状态区显示：
  - 配对屏幕尺寸/坐标/距离；
  - 灯泡亮度 + warming/on/cooling/off；
  - AV 接收器连接状态、播放状态、可用时的分辨率。
- 不显示媒体文件、codec、丢帧、seek 等 AV 专属信息。
- GUI 是否暂停游戏由 Mod Menu 的 `Pause game in device GUIs` 控制（默认关）；投影仪被拆除时自动关闭。

### M2：光学与 wash 编辑（已实现）

- 投掷比（自动/手动）、焦距（自动/手动）、垂直/水平梯形、亮度、wash 滑块。
- 顶部 `Power ON/OFF` 立即发送；服务端切换灯泡预热/冷却。
- 滑块改动后约 200 ms debounce 发送完整 C2S 快照；按钮/Defaults 立即发送；没有 Cancel/Done。
- `Close`/Esc 只关闭，关闭前会把未发送的滑块改动 flush。
- 服务端 `ProjectorSettingsHandler` 校验距离、方块、有限值和范围；`ProjectorBlockEntity.applySettings` 一次性写入。
- 支持 `Defaults` 立即恢复默认值；命令与 GUI 最终写入同一组 block entity 字段，GUI 使用原子 `applySettings`。
- 面板使用 2 列紧凑布局，状态区在 `renderBackground` 中绘制，避免被二次背景模糊覆盖。

### M3：物理模拟开关（已实现）

- 对焦模糊、梯形、wash、灯泡预热四个独立开关；切换即发送。
- 关闭后：
  - 对焦模糊：`blurLod = 0`；
  - 梯形：`ProjectorOptics.uv()` 直接返回未畸变 UV；
  - wash：光学层 `ambientWash = 0`；
  - 预热：灯泡直接到目标亮度，`opticalBrightness` 不等 ramp。
- 开关保存在 block entity NBT，随 `ProjectorSettingsPayload` 同步，专用服务器可用。
- GUI 使用一行紧凑开关（Focus/Keystone/Wash/Warmup），不阻塞 M4 配对功能。
- 对焦模糊当前基于 mipmap/LOD，物理观感一般；后续可评估多级采样、卷积或景深，暂不作为当前阻塞项。

### M4：配对/诊断（配对已实现，诊断未做）

- 线材显式配对已实现：先右键投影仪再右键屏幕（或反向）写入 `screenPos`；再次右键同一设备取消配对选择，点击不兼容设备会改为选择新设备；解除连接为潜行右键设备 A、再潜行右键设备 B，只解除两者连接。选择状态 60 秒超时/断线清除。
- 显式链接允许斜向安装，但仍要求屏幕位于投影仪前方且距离不超过 48 格；`screenPos` 无效时 GUI 显示 `linked target missing`，不会退回自动扫描。
- GUI 状态行显示 `linked`；未连接显示 `not linked`。
- 诊断仍未做：显示配对失败原因（距离/朝向/遮挡）与遮挡检查。
- 显示 AV 输入信号状态，不显示解码细节。
- 顶部可编辑 `Projector` 名称；同一行可编辑当前配对屏幕的 `Screen` 名称。屏幕名会写入所有连通屏幕格，并在投影仪状态行、命令诊断和关联设备 GUI 中显示。

### M5：遥控器 / 远程维护（未做）

- 遥控器 item，可绑定投影仪/接收器。
- 在远处打开同一 GUI，调整光学/音量/播放/配对。
- 远程配对：从观众席为投影仪/接收器选择配对目标（屏幕/投影仪/扬声器），不必靠近设备；线材保留为近距物理配对 fallback。
- 权限、距离、视线、维度和多人并发限制；绑定状态需持久化，并明确潜行解绑/重新绑定流程。
